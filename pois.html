OSM-Import pro Land (Overpass, zuhause vorbereiten)
Automatisch (empfohlen): im Projektordner python3 fetch-pois.py ausführen — schreibt pro Land POIs/<Land>-osm.json mit allen Kategorien (🏥 Medizin, 🐾 Tierarzt, ⛽ Tanken, 💧 Wasser, 🏕️ Camps, 🔧 Werkstätten, 🛂 Grenzposten).
Manuell: overpass-turbo.eu öffnen, Query pro Land:
[out:json][timeout:120]; {{geocodeArea:Namibia}}->.a; ( nwr(area.a)[amenity~"hospital|clinic|doctors|pharmacy|veterinary|fuel|drinking_water"]; nwr(area.a)[shop~"car_repair|car_parts"]; nwr(area.a)[tourism~"camp_site|caravan_site"]; ); out center; dann Export → Rohdaten (JSON) → Datei speichern (z.B. namibia-osm.json)
Zum Schluss hier importieren — eine Datei = ein Layer pro Land, Distanzsuche über 🧭 auf der Karte
